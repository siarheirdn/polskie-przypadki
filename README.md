# Polskie przypadki — trening

Тренажёр польских падежей: в предложение нужно поставить прилагательное и существительное в правильной форме.

**Открыть:** https://siarheirdn.github.io/polskie-przypadki/

На телефоне можно добавить на главный экран («Добавить на экран „Домой“»). После первого открытия работает и без интернета.

## Как устроено

- **37 полей**: 6 падежей × 7 групп рода и числа. Mianownik в единственном числе пропущен, потому что там форма не меняется.
- **Этап 1 — выбор**: прилагательное и существительное выбираются из четырёх вариантов.
- **Этап 2 — wpisywanie**: обе формы вписываются вручную. Регистр не важен, польские буквы важны.
- **Режим «Słabe punkty»**: чаще задаёт вопросы из полей, где больше ошибок.
- **Сессии**: у каждой есть номер, после каждого ответа она сохраняется, и её можно продолжить позже.

Вопросы не хранятся готовыми, а собираются из словаря: около 6000 вариантов.
Внутри поля выбор идёт равномерно: сначала тематическая группа (люди, школа, зоопарк, места, вещи, еда, транспорт), потом слово, потом предложение.

## Где хранятся результаты

В этой версии все сессии и статистика хранятся в браузере устройства.
Чтобы перенести их на другое устройство: **Statystyki → Kopia zapasowa → Pobierz plik**, на другом устройстве **Wczytaj plik**. Совпадающие сессии не дублируются.

## Файлы

| Файл | Что внутри |
|---|---|
| `js/data.js` | существительные со всеми формами, прилагательные, шаблоны предложений, таблица окончаний |
| `js/engine.js` | склонение прилагательных, сборка вопросов, варианты ответа, примеры |
| `js/app.js` | интерфейс, сессии, статистика, хранение |
| `css/style.css` | оформление (светлая и тёмная тема) |
| `sw.js`, `manifest.webmanifest` | работа как приложения и без интернета |

| `tools/build-artifact.js` | сборка в один HTML-файл |

### Как добавить слово или предложение

Существительное в `js/data.js` (массив `NOUNS`):

```js
['lekarz', 'mp', 'people', 'lekarz|lekarza|lekarzowi|lekarza|lekarzem|lekarzu;lekarze|lekarzy|lekarzom|lekarzy|lekarzami|lekarzach', ['nowy', 'miły'], ['visit']],
```

Это лемма, род (`mp` мужской личный, `ma` мужской одушевлённый, `mi` мужской неодушевлённый, `f` женский, `n` средний), тема, формы ед. ч. и мн. ч. в порядке M|D|C|B|N|Ms, подходящие прилагательные и теги.

Предложение в `TEMPLATES`: `___` — место для ответа, `{z}`/`{w}` сами превращаются в `ze`/`we`, где это нужно.
С помощью `tag` и `notTag` предложение привязывается только к подходящим словам, чтобы не получались нелепые сочетания.

После изменений:

```bash
node tools/check.js   # таблица по полям + tools/all-sentences.txt для просмотра
```

Новому прилагательному, которое сочетается с мужскими личными существительными, нужна форма мн. ч. в `VIR` (*nowy → nowi*).
